# Advanced HTML - Techium

HTML5 semantic structure exercises from Task 0 through Task 36.

- Homepages: `0-index.html` to `36-index.html` (the assigned stages only).
- Independent article and informational pages: `article.html`, `about.html`, `latest_news.html`, and `contact.html`.
- Progressive styleguide pages, including headings, lists, quotations, tables, and details.
- Techium favicon and logo assets, plus the images used by Task 36.

Open `36-index.html` for the final page, or `34-styleguide.html` for the final styleguide.
This exercise intentionally uses no CSS; many intermediate stages are exempt from W3C validation per the instructions.
